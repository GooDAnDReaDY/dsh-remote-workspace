# @goodandready/dsh-remote-workspace

Корпоративный плагин удалённой разработки для **DeepSeek Harness (DSH)**:
- 🚀 **Пул SSH-соединений**: Высокопроизводительный пул соединений на базе SSH2 с keep-alive, авто-переподключением и замером задержки (ping).
- 📁 **Файловые операции SFTP**: Потоковое чтение, безопасная атомарная запись, навигация по дереву каталогов и stat.
- 🔄 **3-сторонняя синхронизация (Mirror Sync)**: Двусторонняя синхронизация с контролем конфликтов на основе SHA-256 снапшотов без риска затирания кода.
- 🌐 **SSH-туннели (Port Forwarding)**: Прямой (Local) и обратный (Reverse) проброс портов прямо из интерфейса DSH.
- 🤖 **Компактные инструменты агента**: 4 чистых инструмента (`remote_exec`, `remote_fs`, `remote_sync`, `remote_tunnel`), не перегружающие системный промпт модели.
- 🎨 **Нативный UI**: Карточка настроек, проверка связи "на лету" и селектор удаленных директорий по стандартам DSH.

## Установка

```bash
dsh plugin add @goodandready/dsh-remote-workspace
```

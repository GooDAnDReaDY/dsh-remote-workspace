# DESIGN.md — dsh-remote-workspace

## Product / Purpose
- **Назначение**: Полнофункциональный корпоративный плагин удалённой разработки для DeepSeek Harness (DSH). Позволяет подключаться к удалённым серверам по SSH, работать с файловой системой через SFTP, вести двустороннюю 3-way синхронизацию без конфликтов, пробрасывать порты и давать агенту LLM компактный набор инструментов для удалённого шелла и файлов.
- **Аудитория**: Разработчики и инженеры, использующие DSH для работы с проектами на VPS, удаленных серверах, облачных инстансах и MiniPC.
- **Статус**: В активной разработке (MVP).

## User Surfaces
- **Web/UI**: Нативная карточка настроек профилей хостов (Settings -> Remote Workspace), селектор удаленной рабочей папки, индикатор текущего подключения в статусе.
- **DSH UI / settings / slots**:
  - Карточка настроек: `settings.plugin.item` для `@goodandready/dsh-remote-workspace`.
  - Статусный чип/слот подключения в шапке / сайдбаре.
- **API**: HTTP эндпоинты `/api/remote-workspace/hosts`, `/api/remote-workspace/test`, `/api/remote-workspace/browse`, `/api/remote-workspace/sync`, `/api/remote-workspace/tunnels`.
- **CLI / Tools**:
  - `remote_exec`: выполнение команд на сервере.
  - `remote_fs`: чтение, атомарная запись, патч и stat файлов.
  - `remote_sync`: запуск 3-way синхронизации с контролем конфликтов.
  - `remote_tunnel`: создание/остановка туннелей port forwarding.
- **Документация**: `README.md` (EN), `README.ru.md` (RU), `README.zh.md` (ZH), технические спецификации в `docs/`.

## Visual Direction
- **Атмосфера**: Премиальный инженерный интерфейс уровня VS Code Remote / Linear / JetBrains Gateway. Строгая типографика, мгновенный отклик, визуализация сетевого состояния (пинг, ОС, туннели).
- **Утверждённые референсы**: Нативные CSS токены DSH (`--dsw-*`, `--dsw-color-*`), карточки с мягкими скруглениями (`rounded-xl`), моноширинные теги и статус-бэйджи.
- **Не копировать**: Спагетти-интерфейс старого dsh-remote, не инжектить принудительно сторонние плагины в `cordis.patch.yml`.

## Foundations
- **Цвета и роли**:
  - `Online / Connected`: Emerald/Green (`#10b981`).
  - `Connecting / Syncing`: Amber/Yellow (`#f59e0b`).
  - `Error / Disconnected`: Rose/Red (`#f43f5e`).
  - `Tunnel active`: Sky/Cyan (`#0ea5e9`).
- **Типографика**: Стандартный стек шрифтов DSH с `font-mono` для хостов, IP, портов и путей.
- **Сетка и отступы**: 8pt grid, компактные формы с валидацией "на лету".

## Components And States
- **HostManagerCard**:
  - Список настроенных машин с иконками ОС, пингом и статусом ключа.
  - Модальное окно/форма добавления (Host, Port, User, Auth: Key / Password / Agent, JumpHost).
  - Кнопка «Проверить подключение» с индикацией задержки (ping ms) и версии SSH.
- **RemoteDirectoryPicker**:
  - Дерево каталогов с навигацией по клику, breadcrumbs и кнопкой «Выбрать как Workspace».
- **TunnelManager**:
  - Таблица активных Local и Reverse туннелей с тумблерами включения/выключения.
- **Loading / Empty / Error States**:
  - Скелетоны при чтении SFTP дерева.
  - Ясные подсказки при ошибках авторизации (HostKey mismatch, Auth fail, Timeout, Permission denied).

## User Flows
1. **Настройка**: Открыть настройки -> Добавить хост -> Нажать «Проверить» -> Зелёный статус -> Сохранить.
2. **Открытие проекта**: Выбрать хост -> Открыть Remote Directory Picker -> Выбрать папку -> Активировать как Remote Workspace.
3. **Работа агента**: LLM получает компактные инструменты `remote_*`, видит активный хост в system prompt и безопасно редактирует код.

## Do / Don't
- **Do**:
  - Использовать строгие типы Schemastery для настроек и аргументов тулов.
  - Всегда проверять TOFU known_hosts для защиты от спуфинга.
  - Делать атомарную запись файлов во избежание повреждения кода при сетевых разрывах.
  - Поддерживать три языка (EN, RU, ZH) в интерфейсе.
- **Don't**:
  - Забивать контекст LLM десятками однотипных функций `rw_*`.
  - Блокировать Event Loop Node.js долгими SFTP операциями — использовать потоки и Promise pool.
  - Хранить пароли в открытых логах.

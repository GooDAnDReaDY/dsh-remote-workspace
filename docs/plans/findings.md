# findings.md — dsh-remote-workspace

## Ключевые выводы анализа dsh-remote
1. Преимущество 3-way sync: snapshot хешей предотвращает перезапись изменений при одновременном редактировании на сервере и локально.
2. Проблема 21 инструмента rw_*: перегружает LLM prompt. В новом плагине объединяем в 4 сбалансированных инструмента: `remote_exec`, `remote_fs`, `remote_sync`, `remote_tunnel`.
3. Модульность: вместо спагетти в `index.js` реализуем 4 отдельных Cordis сервиса.
4. UI: использование нативных CSS переменных DSH, чистый React, поддержка i18n (EN/RU/ZH).
